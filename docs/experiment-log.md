# Safety and experiment log

Use this page for a running record, or create one Markdown file per experiment using the [document template](README.md#suggested-log-format).

## Safety checklist

- Complete the safety briefing and trainer assessment before independent operation.
- Check connections, calibration, workspace, and emergency procedures before each trial.
- Keep people and obstacles clear of the robot’s movement area.
- Change one control variable at a time and record the result.
- Leave the workspace and robot in the documented safe state after testing.
